# 产品需求文档 (PRD)

## 家教日程管家 (TutorSchedule)

**版本**：1.0.0
**日期**：2026-08-10
**状态**：开发中

---

## 1. 产品概述

### 1.1 产品定位

一款专为私人家庭教师设计的本地日程管理工具。无需联网，数据全本地存储，帮助教师高效管理学生信息、排课安排、教学记录和收入统计。

### 1.2 目标用户

| 角色 | 描述 | 规模 |
|------|------|------|
| 主要用户 | 私人家庭教师 | 1对多授课，学生5-30人 |

### 1.3 核心价值

- **信息集中化**：学生档案、课程安排、教学记录统一管理
- **排课可视化**：周视图/月视图直观展示课程安排
- **数据可量化**：课时统计、收入预估、学习进度一目了然
- **完全离线**：无需网络，数据安全存储在本地

### 1.4 目标平台

| 平台 | 最低版本 | 优先级 |
|------|----------|--------|
| Android | API 21 (5.0) | P0 |
| iOS | 13.0 | P0 |
| Web | Chrome 80+ | P1 |

## 2. 功能需求

### 2.1 学生信息管理 (P0)

#### 2.1.1 功能描述

管理所有学生的基本信息，支持快速搜索和筛选。

#### 2.1.2 数据字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 自动 | UUID 主键 |
| name | string | 是 | 学生姓名 |
| grade | string | 是 | 年级（如：高一、初三） |
| school | string | 否 | 学校名称 |
| phone | string | 否 | 学生电话 |
| parentPhone | string | 否 | 家长电话 |
| subjects | list | 否 | 科目列表（如：数学、英语） |
| tags | list | 否 | 自定义标签（如：重点跟进） |
| notes | string | 否 | 备注信息 |
| createdAt | datetime | 自动 | 创建时间 |
| updatedAt | datetime | 自动 | 更新时间 |

#### 2.1.3 功能清单

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 学生列表 | P0 | 按姓名排序展示所有学生 |
| 添加学生 | P0 | 填写表单创建学生档案 |
| 编辑学生 | P0 | 修改学生信息 |
| 删除学生 | P0 | 删除学生（需确认） |
| 学生详情 | P0 | 查看完整档案和关联课程 |
| 搜索筛选 | P0 | 按姓名/年级/科目搜索 |
| 科目标签 | P1 | 为学生添加科目标签 |

#### 2.1.4 页面流程

```
学生列表 → 点击学生 → 学生详情
         → 点击添加 → 添加学生表单
学生详情 → 点击编辑 → 编辑学生表单
         → 点击删除 → 确认弹窗 → 删除
```

---

### 2.2 课程安排 (P0)

#### 2.2.1 功能描述

管理所有课程的时间安排，支持重复规则和冲突检测。

#### 2.2.2 数据字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 自动 | UUID 主键 |
| studentId | string | 是 | 关联学生 |
| subject | string | 是 | 科目 |
| dayOfWeek | int | 条件 | 1-7（周一到周日），重复课程必填 |
| startTime | datetime | 是 | 开始时间 |
| endTime | datetime | 是 | 结束时间 |
| repeatRule | string | 否 | none/weekly/biweekly |
| repeatEndDate | datetime | 否 | 重复结束日期 |
| location | string | 否 | 上课地点 |
| isActive | bool | 是 | 是否启用 |
| reminderMinutes | int | 否 | 提前提醒分钟数（默认30） |

#### 2.2.3 功能清单

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 周视图 | P0 | 按星期展示课程安排 |
| 月视图 | P0 | 月历形式展示课程 |
| 添加课程 | P0 | 选择学生、科目、时间 |
| 编辑课程 | P0 | 修改课程安排 |
| 删除课程 | P0 | 删除课程（需确认） |
| 重复规则 | P0 | 支持单次/每周/每两周 |
| 冲突检测 | P0 | 检测时间重叠并提示 |
| 地点设置 | P1 | 设置上课地点 |

#### 2.2.4 页面流程

```
课程安排（周视图/月视图）→ 点击添加 → 新建课程表单
                        → 点击课程 → 编辑课程表单
新建课程 → 选择学生 → 选择科目 → 设置时间 → 设置重复规则 → 保存
         → 冲突检测 → 提示冲突 → 用户确认/取消
```

### 2.3 课程记录 (P0)

#### 2.3.1 功能描述

每次课后记录教学内容、作业布置和学生表现评分。

#### 2.3.2 数据字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|

| homework | string | 否 | 作业布置 |
| rating | int | 否 | 学生表现评分（1-5，默认3） |

#### 2.3.3 功能清单

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 记录列表 | P0 | 按时间倒序展示记录 |
| 添加记录 | P0 | 填写教学内容、评分等 |
| 编辑记录 | P0 | 修改课程记录 |
| 删除记录 | P0 | 删除记录 |
| 评分系统 | P0 | 1-5星评分 |
| 按学生筛选 | P1 | 查看某学生的所有记录 |

### 2.5 数据分析 (P1)

#### 2.5.1 功能描述

提供课时统计、收入预估和科目分布的可视化图表。

#### 2.5.2 功能清单

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 时间段选择 | P0 | 本周/本月/本年 |
| 课时统计 | P0 | 总授课时长 |
| 收入预估 | P0 | 课时费 × 课时数 |
| 科目分布 | P1 | 饼图展示各科目占比 |
| 每日课时 | P1 | 柱状图展示每日课时 |
| 数据导出 | P1 | 导出为 CSV 格式 |

#### 2.5.3 计算公式

```
预估收入 = 总课时(小时) × 课时费单价(元/小时)
```

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 目标 |
|------|------|
| 列表加载 | < 500ms |
| 数据库查询 | < 100ms |
| 应用启动 | < 2s |
| 支持数据量 | 1000+ 课程记录 |

### 3.2 安全要求

- 数据存储在本地 SQLite 数据库
- 无网络传输，无隐私泄露风险

### 3.3 兼容性要求

- Android：支持 API 21+ (Android 5.0+)
- iOS：支持 iOS 13.0+
- Web：支持 Chrome 80+, Safari 14+, Firefox 80+

## 4. 技术架构

### 4.1 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 框架 | Flutter 3.x | 跨平台 UI |
| 状态管理 | Riverpod 2.x | 响应式状态管理 |
| 数据库 | Drift (SQLite) | 本地关系型数据库 |
| 路由 | go_router | 声明式路由 |
| 图表 | fl_chart | 数据可视化 |
| 通知 | flutter_local_notifications | 本地推送 |

### 4.2 数据库表结构

```
students          学生信息表
├── id            UUID 主键
├── name          姓名
├── grade         年级
├── school        学校
├── phone         电话
├── parentPhone   家长电话
├── subjects      科目 (JSON)
├── tags          标签 (JSON)
└── notes         备注

course_records    课程记录表
├── id            UUID 主键
├── studentId     外键 → students
├── subject       科目
├── date          日期
├── duration      时长(分钟)
├── content       教学内容
├── homework      作业
└── rating        评分(1-5)

schedules         课程安排表
├── id            UUID 主键
├── studentId     外键 → students
├── subject       科目
├── dayOfWeek     星期(1-7)
├── startTime     开始时间
├── endTime       结束时间
├── repeatRule    重复规则
├── location      地点
└── reminderMinutes 提前提醒

progress_entries  学习进度表
├── id            UUID 主键
├── studentId     外键 → students
├── subject       科目
├── topic         知识点
├── masteryLevel  掌握程度(1-5)
└── notes         备注
```

## 附录

### A. 评分标准

| 评分 | 含义 | 描述 |
|------|------|------|
| 1 | 很差 | 完全不理解，需要重新讲解 |
| 2 | 较差 | 理解困难，需要大量练习 |
| 3 | 一般 | 基本理解，需要巩固 |
| 4 | 良好 | 理解较好，少量问题 |
| 5 | 优秀 | 完全掌握，可以进阶 |

### B. 重复规则

| 规则 | 说明 |
|------|------|
| none | 不重复，单次课程 |
| weekly | 每周重复 |
| biweekly | 每两周重复 |
